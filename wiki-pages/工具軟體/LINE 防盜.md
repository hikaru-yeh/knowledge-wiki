# LINE 防盜：關密碼登入、語音信箱

2026/04/01 爆發 LINE 帳號大量被盜事件，台哥大用戶尤其受影響。

**兩個防盜步驟：**

1. **關閉密碼登入**  
   → 改用掃 QR Code 方式雙重認證登入

2. **取消語音信箱**  
   → 向電信公司申請取消語音信箱功能  
   → 台哥大用戶可在 APP 內直接設定（設定 → 門號設定）  
   → 其他電信公司請聯絡客服
