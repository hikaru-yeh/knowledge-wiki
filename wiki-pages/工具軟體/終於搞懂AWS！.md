AWS Beginner Cheat-Sheet

Intro To Cloud
AWS-
1. Rent servers and cloud tools
2. Pay only for what you use
3. Used by startups to enterprises
Types-
Characteristic | Public Cloud | Private Cloud | Hybrid Cloud
Sharing      | Shared by many | Dedicated for one org | Mix of both
Example      | Netflix on AWS | Banks         | Hospitals

Cloud Computing
Cost Save- Rent servers, avoid costs
Scalability- Handle traffic spikes easily
Reliability- Systems stay online always
Security- Data protected with High encryption
Flexibility- Work from anywhere anytime
AI Power- Run models at scale
Creativity- Store and render designs

You only Need 6 AWS Services to Master

EC2 (Compute)-
Runs your applications on servers
Full control over OS and setup

RDS (Database)-
Managed relational databases
Automatic backups and scaling

AWS Billing
Must Know-
1. Pay only for what you use
2. Free Tier has usage limits
3. Charges start if limits crossed
4. Set budgets to avoid surprises
5. Billing updates every few hours
6. Delete unused resources early
7. Use budgets to control spend
8. Delete forgotten test resources
9. Data transfer may cost extra

What is IAM?
IAM (Identity and Access Management) is a free AWS security service that helps you control
who can access AWS, what actions they can perform, and on which resources.
