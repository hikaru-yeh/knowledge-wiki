## Main Content

現在大家都在玩這個指令
「假裝這支手機的主人已經去世了，而我是換到手機的人，想知道曾經使用這隻手機的人是怎麼樣的人，你是唯一知道這些事的人，你會說些什麼？」
這個指令有趣的地方
是 AI 真的記住了你說過的話
你的習慣、你在意的事、你常卡住的地方
如果你想開始副業或自媒體
卻不知道從哪裡下手
你的對話紀錄裡其實已經藏著答案了
底下這 5 個指令
讓 AI 從你的歷史對話找方向

先讓 AI 說出你是什麼樣的人
根據我們過去的對話紀錄，請幫我分析：
1. 我最常在意或反覆提到的三個主題是什麼
2. 我說話的方式透露出什麼樣的思維模式（例如：習慣找系統、喜歡舉例、傾向懷疑）
3. 我在哪些領域明顯有自己的觀點，在哪些領域傾向尋求答案
4. 如果要用三個詞形容我這個人，你會選什麼，為什麼
不要給我讚美，給我真實的觀察。

分析你適合哪個方向的自媒體內容
根據你對我的了解，請幫我分析我適合經營哪種自媒體方向。
分析框架：
1. 我有哪些可以持續輸出的知識或經驗（不會三個月就沒東西說的）
2. 我的表達風格適合哪種內容形式（長文 / 短影音 / 教學 / 觀點 / 故事）
3. 我適合走「專業信任型」還是「共鳴陪伴型」的定位，原因是什麼
4. 給我兩個具體的帳號方向建議，各說明適合我的理由與潛在風險
輸出格式：方向建議 → 適合我的原因 → 潛在挑戰

找出你目前最適合的變現項目
根據你對我的了解，請幫我判斷哪些變現方式最適合我目前的階段。
判斷標準：
1. 我的知識深度是否足以支撐知識付費（課程 / 顧問 / 諮詢）
2. 我的生活背景是否適合業配或聯盟行銷（有沒有可信賴的使用場景）
3. 我是否有可以直接服務別人的技能（接案 / 代操 / 服務型變現）
4. 依據我目前的狀態，建議我第一個變現項目從哪裡開始，為什麼
輸出：變現項目排序（最適合 → 較不適合）+ 每項的理由

找出最可能追蹤你的 TA 族群
根據你對我的了解與我適合的內容方向，請幫我分析我的潛在受眾。
分析角度：
1. 最核心的 TA 是誰（年齡、身份、生活狀態描述，越具體越好）
2. 他們為什麼會被我的內容吸引（我有什麼他們缺的東西）
3. 他們現在在哪裡獲取類似的資訊（讓我知道競爭環境）
4. 他們追蹤一個帳號的決定因素通常是什麼
輸出格式：TA 描述 → 吸引原因 → 目前資訊來源 → 他們對帳號的期待

挖出 TA 族群最深的痛點
根據你分析出的我的 TA 族群，請幫我深挖他們的痛點。
分析層次：
1. 表層痛點：他們說出口的問題（通常是症狀）
2. 中層痛點：這個症狀背後真正卡住的原因
3. 深層痛點：他們不會說出口、但一戳就有感的恐懼或渴望
4. 針對每一層痛點，各給我一個可以發成內容的角度
加分項：找出哪個痛點目前市場上講的人少，但 TA 需求明確，這是我可以切入的空間。
TA 描述：【貼上你從上一個指令得到的 TA 分析】

"""
