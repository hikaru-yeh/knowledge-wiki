## 摘要

Tubelens 是一個 Chrome 瀏覽器擴充功能，整合 Claude AI，讓你一鍵把 YouTube 影片轉成多種形式的知識萃取，目前免費使用。

## 核心功能

| 功能 | 說明 |
|------|------|
| **影片摘要** | 一鍵生成影片重點摘要，不用從頭看完 |
| **心智圖** | 將影片結構可視化，掌握知識架構 |
| **留言分析** | 分析影片留言區的觀點與討論趨勢 |
| **雙語字幕** | 自動生成並顯示雙語字幕，學語言更有效率 |

## 適用情境

- 看長篇教學或演講影片，快速抓出重點
- 學習硬知識但不想從頭看完每一分鐘
- 追蹤國際內容但語言有障礙

## 注意事項

- 依賴 Claude AI API 運行，若 Claude 服務有限制可能受影響
- 免費方案用量有限，使用前確認當前條款
