## Muse 三層系統（打造電馭大腦）

Karpathy → 周加恩 → Vista Muse 的演化路徑，建構個人 AI 知識系統：

| 層 | 名稱 | 功能 |
|----|------|------|
| 第一層 | **Zettelkasten 層** | 原子化筆記，每個想法獨立卡片 |
| 第二層 | **工作層** | 當前專案、進行中任務 |
| 第三層 | **個人層** | 長期目標、個人成長記錄 |

**核心理念**：AI 是大腦的延伸，而非替代品。系統越個人化，AI 輔助效果越好。

## Karpathy Vibe Coding 心法

**三大通病：**
1. 讓 AI 主導架構決策（人應掌舵）
2. 沒有測試就接受 AI 輸出
3. 上下文管理混亂

**四大法則：**
1. **先想再動**：理解需求後才開始寫 prompt
2. **簡單優先**：最簡單的解法幾乎永遠更好
3. **精準修改**：diff 越小越好，避免大範圍重寫
4. **目標驅動**：每個 prompt 都對應明確的功能目標

## Claude Code 50 招（Vibe Coding 實戰）

核心技巧分類：
- **初始化**：用 CLAUDE.md 給足夠的系統上下文
- **迭代**：小步提交，保持 git 歷史乾淨
- **驗證**：每個功能完成後立即測試
- **除錯**：讓 Claude 讀錯誤訊息，不要自己翻譯
