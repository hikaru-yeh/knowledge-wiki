如何使用 /goal
史上最簡單的 AI Agent 指令，適用於 Claude Code、Codex、Hermes

① 整段指令 (唯一需要輸入的內容)

>                                         /goal [你的任務或目標]

在你的 AI 工具中輸入 - Agent 會確認並開始執行，完成後回傳結果

    Codex Desktop 設定 (3個步驟)

1   啟用目標功能
    Codex Desktop → Settings → Configuration → 將 goals 設為 true

2   開啟終端機，啟動全自動模式 (減少確認提示)
    codex --approval-mode full-auto

3   開始輸入任務
    /goal [你的任務或目標]
