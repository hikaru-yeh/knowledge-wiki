本週 GitHub Trending 前 5 名，有 3 個是 skills repo。
有人把 Karpathy 的 LLM 失敗觀察整理成一份 CLAUDE.md，+25,836 星；Matt Pocock 的工程 skill 包 +18,218 星；Addy Osmani 的 production-grade skills +6,179 星。三個同週擠進前五，這不是巧合。

拿那份最熱門的來說，Forrest Chang 把 Karpathy 描述的三種 LLM 失敗模式，寫成 agent 看得懂的行為規格：不要靜默假設、不要隱藏困惑、不要省略取捨。
聽起來像常識，但 LLM 不講就不會做。一份 Markdown 檔解決的事，累積快 10 萬星。

有趣的是三個 repo 定位完全不同。Karpathy 的規範「不該做什麼」，Pocock 的教「怎麼做」（TDD、壓縮輸出、git 防護），Osmani 的走企業全流程（define → plan → build → verify → review → ship）。
三層加起來，幾乎覆蓋了一個工程師日常會踩的所有坑。

兩年前大家在選 npm 套件，現在開始在選 skills。差別是：套件解決程式問題，skill 解決行為問題，讓 AI agent 知道什麼時候該停下來問你，而不是自己亂衝。
這可能是 AI coding 工具鏈裡，最安靜但最重要的一層基礎設施。
