**Claude Octopus**（社群開發者開源工具，非官方）讓最多 8 個 AI 模型同時審查程式碼，互相抓漏。

**核心機制：75% 共識門檻**  
三個 model 跑完，如果有一個不同意，會攔下來讓你審視，而非直接放行。

**常見角色分工：**
- Claude：指揮協調
- Codex：深度實作
- Gemini：生態系與資安

**Debate 功能：**讓多個 AI 對技術決策正式辯論（如 monorepo vs microservices），各講立場，再看共識。

**與 Codex plugin 比較：**
- Codex plugin（OpenAI 官方）：Claude + Codex 雙引擎，輕量好上手，用現有 ChatGPT 訂閱
- Octopus：最多 8 個 provider 同時跑 + consensus gate，範圍更廣但設定更多

Octopus 目前 2.6k GitHub Stars，有 subreddit r/ClaudeOctopus。
