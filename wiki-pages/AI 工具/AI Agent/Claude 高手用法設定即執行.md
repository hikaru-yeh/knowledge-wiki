# Claude 高手用法：設定即執行

Claude Code 四大進階功能，讓使用方式從「我問你答」升級為「我設定，你執行」：

**1. CLAUDE.md**  
不再每次重講規則，一份設定檔讓 Claude 永遠記住你的工作方式。

**2. Skills**  
不再手動重複工作，把重複任務封裝成可呼叫的 Skill 指令。

**3. Subagents**  
不再一次只做一件事，派遣 Subagents 小隊並行處理多個任務。

**4. Hooks**  
不靠 AI 記得該做什麼，設定 Hooks 讓指定事件自動觸發對應動作。

每項功能都附上實際範例，今天就能上手。
