## Main Content

如果您有在使用 3T(Tailscale、Termius 跟 Tmux)，用手機操控家裡的 AI（例如 Claude Code、Codex 或 OpenCode），其實有一個方法可以claude app手機操控它們。
目前 Claude Code 跟 Codex 都能夠直接用手機操控，讓家裡的 AI 能夠運作，甚至連到別臺電腦。而 OpenCode可以透過 tmux 讓 Claude Code 去操控它，就變成 AI 上的 AI。

我是用 Typeless 語音輸入，講了一大段話之後基本上不用改。

之前用3T字比較小看起來痛苦，編輯也不方便。
現在用claude或者codex的app在手機上字比較大，語音輸入後的編輯也比較方便，方便很多。
