九個讓 Claude Code 工作效率大幅提升的鮮為人知 repo：

---

## 1. claude-mem ⭐ 77,669

**GitHub**: [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)

跨 session 持久記憶。自動擷取 agent 每次 session 的行動，AI 壓縮後注入下次 session。支援 Claude Code / Codex / Gemini / Copilot 等。

## 2. UI UX Pro Max ⭐ 81,986

**GitHub**: [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

161 條推理規則 + 67 種 UI 風格的設計智慧技能，讓 AI 生成媲美資深設計師的多平台 UI。

## 3. n8n-MCP ⭐ 21,208

**GitHub**: [czlonkowski/n8n-mcp](https://github.com/czlonkowski/n8n-mcp)

MCP server，讓 Claude Code / Windsurf / Cursor 直接構建 n8n workflow。提供完整 n8n node 文件、屬性、操作的 AI 可存取介面。

## 4. obsidian-skills ⭐ 32,639

**GitHub**: [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)

讓 Agent 會用 Obsidian 的技能集：Obsidian Markdown / Bases / JSON Canvas / CLI 操作。

```bash
npx skills add https://github.com/kepano/obsidian-skills
```

## 5. LightRAG ⭐ 35,621

**GitHub**: [hkuds/LightRAG](https://github.com/hkuds/LightRAG)

EMNLP2025 論文實作，輕量快速 RAG。處理大型文件比傳統 RAG 更快、更精準、token 消耗更少。

## 6. ECC (everything-claude-code) ⭐ 189,098

**GitHub**: [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code)

Agent harness 效能優化系統。包含 Skills / Instincts / Memory / Security / Research-first 開發流程。

## 7. Superpowers ⭐ 已知

**GitHub**: [obra/superpowers](https://github.com/obra/superpowers)

為 Claude Code 注入 brainstorming / debugging / TDD / code review 等核心能力的 Skill 框架。

## 8. Awesome Claude Code ⭐ 44,617

**GitHub**: [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code)

精選 Claude Code 相關資源：Skills / Hooks / Slash Commands / Agent Orchestrators / Plugins，社群持續更新。

## 9. GSD (Get Shit Done) ⭐ 63,641

**GitHub**: [gsd-build/get-shit-done](https://github.com/gsd-build/get-shit-done)（現移至 open-gsd/get-shit-done-redux）

輕量 meta-prompting + context engineering + spec-driven 開發系統。極速交付、不容出錯的直接工作流。
