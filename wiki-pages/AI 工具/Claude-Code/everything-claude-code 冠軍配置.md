**everything-claude-code** 是一個開源的 Claude Code 完整配置包，開源後數天即累積 12 萬 GitHub Stars。作者以這套配置參加黑客松並獲得冠軍。

涵蓋範圍：
- Agent 設置方式
- Skills 撰寫規則
- 快捷指令配置
- 規則定義
- MCP 接入方法

實戰技巧包含：
- 如何省 Token、挑選模型、壓縮系統提示
- 讓 AI 有跨對話記憶（關掉對話下次接著做）
- 讓 AI 從每次對話自己總結經驗（越用越順手）
- 輸出品質評估打分機制
- 並行任務場景設計
- 多 Agent 協作分工（避免互相打架）

支援 Windows 和 Mac 直接執行，全部來自實戰驗證。
