claude code
04/21/26
如果你用 claude code 一段時間，你可以請 claude code 提取你的 思考脈絡、決策模型、Debug 習慣... 等，然後寫成一個 skill 之後，請他設計成強制的 Hook，之後不管是開發、迭代，都等於有一個我的影分身及時介入。
一般的 skill 需要等 LLM 想到要用才用，寫進去 Hook 就會強制一定要用了。

Hook 相對 Claude.md 還有 skill 都來得有強制性，目前測試 80%的時間都有控制住，省下很多來來回回的時間。

可以嘗試用看看喔，效果頗好的
