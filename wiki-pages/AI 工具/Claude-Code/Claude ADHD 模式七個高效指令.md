# Claude ADHD 模式：七個高效指令

Claude 隱藏的「ADHD Mode」——7 個針對注意力困難設計的提示詞：

1. **5 Minute Brain Dump**  
   「我腦中有一堆想法無法集中。幫我清空所有想法，然後分類：現在做 / 稍後做 / 刪除。回應要簡短有力。」

2. **Task Untangler**  
   「我迴避 [任務] 很多天了也不知道為何。把它拆成最小步驟（每步不超過 5 分鐘），找出阻礙原因（無聊 / 恐懼 / 不知所措），每步前給一句動力話。」

3. **Hyperfocus Hijacker**  
   「我剛掉進 [主題] 的超專注漩渦。幫我擷取所有有用想法，再建立結構化計畫把這股能量導向有生產力的事，並建立書籤讓我之後能無縫回來。」

4. **Body Double Bot**  
   「接下來 [X] 分鐘，充當我的虛擬陪同者。我需要完成 [任務]。定期確認、問我做了什麼、慶祝小勝利、輕輕糾偏。保持高能量低壓力。」

5. **Overwhelm Translator**  
   「所有事情都感覺緊急讓我動彈不得。拿這份清單：[清單]。按真實緊迫度排序，告訴我應該先做的唯一一件事和確切原因，然後隱藏其餘的讓我專注。」

6. **Dopamine Task Designer**  
   「我很難開始和完成 [無聊任務]，因為我的大腦拒絕投入。重新設計整個體驗讓它更刺激——加遊戲化、時間挑戰、獎勵、新奇感或競爭感。給我一個 60 秒內就能開始的版本，不需要額外工具。」

7. （第七個指令在原文截斷，未完整記錄）
