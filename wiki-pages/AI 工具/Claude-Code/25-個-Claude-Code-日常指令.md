## Main Content

25 Claude CODE COMMANDS I USE DAILY.

AUTOMATION
→ /loop — repeat a task on interval (polls, tests, PRs)
→ /schedule — cloud tasks that run while you sleep
→ /btw — ask a side question without killing the current task
→ /advisor — escalate to a stronger model for hard decisions

POWER
→ /remote-control — run Claude Code from your phone
→ claude --chrome — full browser control from terminal
→ /init — auto-generate project memory (CLAUDE.md)

SESSION
→ /compact — compress context, keep working
→ /clear — wipe chat, fresh start
→ /resume — pick up old sessions
→ /fork — branch your conversation like git
→ /rewind — roll back mistakes instantly

CONTROL
→ /model — switch Sonnet ↔ Opus mid-session
→ /effort — set thinking depth (low to max)
→ ULTRATHINK — one word, 32K token reasoning
→ /fast — same Opus, 2.5x speed
→ /plan — outline before touching code

CONTEXT
→ /context — visualize how full your window is
→ /cost — see exactly what you're spending
→ /diff — review every change before committing

UNDERRATED
→ /review — full code review (bugs, style, performance)
→ /export — save any session as shareable text
→ /compact [instructions] — tell it WHAT to keep when compressing
→ /config — open settings without leaving the session
→ /permissions — see exactly what Claude can read/write
→ /caveman — third-party skill, cuts output tokens ~75%

That's 25. Most Claude Code users know maybe 5.

If This Looks Complex, Use It Like This:
Start With Just 3:
• /loop → Automate One Repeated Task
• /schedule → Run Something While You Sleep
• /advisor → Use It For Better Decisions
Ignore The Rest For Now.
That Alone Is Already Leverage.
