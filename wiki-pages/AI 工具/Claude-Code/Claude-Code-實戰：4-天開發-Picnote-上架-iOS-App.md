## Main Content

零基礎也能 4 天開發 iOS App？
這位老哥用 Claude Code 證明了可能性，而且已經完成蘋果官方審核。
他開發的 App 叫 Picnote，解決了個常見痛點：
平時刷影片看到喜歡的內容就隨手截圖，結果相簿裡幾百張截圖堆積如山，想找的時候根本找不到。
Picnote 的使用流程超順暢：
1. 從相簿選取截圖
2. 一鍵分享到 Picnote
3. AI 自動解析圖片內容
4. 輸出結構化的 Markdown 筆記
5. 還能直接同步到 Obsidian
後端架構也跟上時代，全採用雲端服務：函數計算、表格儲存、物件儲存。
這套中文開發教學非常詳盡，涵蓋從開發到上架的完整流程。對於想學習 App 開發的朋友，絕對值得一看。
