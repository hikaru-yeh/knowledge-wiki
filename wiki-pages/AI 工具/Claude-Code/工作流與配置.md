## 穩定工作流架構

**核心哲學（建構 Claude Code 穩定工作流）：**
- **Skill 設計哲學**：每個 Skill 應有明確觸發條件與退出條件
- **交付線設計**：定義完成標準（Done = 可交付，而非「差不多好了」）
- **最小版本原則**：先完成最小可運作版本，再迭代

**Claude Agent 四種權限模式：**
| 模式 | 說明 | 適用場景 |
|------|------|----------|
| Ask | 每步驟都詢問 | 高風險操作 |
| Auto | 全自動執行 | 有完整測試覆蓋的流程 |
| Plan | 先規劃再執行 | 複雜多步驟任務 |
| Bypass | 跳過確認 | CI/CD 流水線 |

**危險指令識別清單（操作前務必確認）：**
- 檔案系統：`rm -rf`、`rmdir /s`
- 資料庫：`DROP`、`DELETE FROM`（無 WHERE）
- Git：`--force`、`reset --hard`
- 管道執行：`| bash`、`| sh`、`eval`
- 部署：`deploy`、`push`、`publish`

## ADHD 輔助七指令

1. `下一步是什麼？` — 打破啟動障礙
2. `把這個分解成5步` — 化繁為簡
3. `幫我起個頭` — 解除拖延
4. `檢查我目前的進度` — 即時回饋
5. `這樣夠好了嗎？` — 完美主義解藥
6. `幫我想替代方案` — 跳出思維定勢
7. `總結我們做了什麼` — 工作記憶輔助

## 排程與事件驅動（Routines）

Claude Code 支援三種自動化觸發：
- **排程（Schedule）**：cron 語法定時執行
- **GitHub 事件**：PR、Issue、Push 觸發
- **API 觸發**：外部系統 webhook 呼叫
