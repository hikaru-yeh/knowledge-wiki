## 概述

Awesome LLM Apps 是 100+ 即用型 AI Agent 與 RAG 應用模板集。非策展連結集，而是可直接 clone、運行、修改、上線的完整專案。

- 112k stars / Apache-2.0 授權
- 3 行指令即可啟動
- 供應商中立：支援 Claude / Gemini / GPT / Llama / Qwen / xAI / Ollama 本地模型

## 13 大分類

### 1. Starter AI Agents（12 個）

單檔 agent，只需 API key。旅行、數據分析、音樂生成、梗圖、醫療影像、財務。

### 2. Advanced AI Agents（21 個）

含工具、記憶、推理能力。Deep Research Agent / VC 盡調團隊 / 財務教練 / 電影製作 / 投資 / 詐騙調查 / 記者 Agent。

### 3. Autonomous Game-Playing Agents（3 個）

端對端遊戲：西洋棋 / 井字遊戲 / 3D Pygame。

### 4. Multi-Agent Teams（13 個）

多 agent 協作。財務團隊 / 遊戲設計 / 法律 / 房地產 / 教學 / 旅行規劃。

### 5. Voice AI Agents（5 個）

語音輸入輸出。語音導覽 / 客服語音 / 保險理賠語音 / Voice RAG。

### 6. MCP Agents（5 個）

透過 Model Context Protocol 整合工具。Browser MCP / GitHub MCP / Notion MCP / Travel MCP / Multi-MCP Router。

### 7. RAG（20 個）

從基礎 chain 到 agentic pattern。Agentic RAG + Embedding Gemma / Corrective RAG / Hybrid Search RAG / Knowledge Graph RAG / Multimodal RAG。

### 8. Agent Skills（19 個可重用技能）

模組化技能檔。Academic Researcher / Code Reviewer / Content Creator / Data Analyst / Decision Helper / Project Planner。

### 9. LLM Apps with Memory（6 個）

持久狀態對話。ArXiv Agent with Memory / Travel Agent with Memory / Stateful Chat。

### 10. Chat with X Tutorials（6 個）

把資料源變聊天介面。Chat with GitHub / Gmail / PDF / Research Papers / Substack / YouTube。

### 11. LLM Optimization Tools（2 個）

降低成本。Toonify Token Optimization / Headroom Context Optimization。

### 12. Fine-Tuning Tutorials（2 個）

Gemma 3 與 Llama 3.2 微調食譜。

### 13. Framework Crash Courses（2 個）

Google ADK 與 OpenAI Agents SDK 完整教學。

## 快速開始

```bash
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps/starter_ai_agents/ai_travel_agent
pip install -r requirements.txt
streamlit run travel_agent.py
```
