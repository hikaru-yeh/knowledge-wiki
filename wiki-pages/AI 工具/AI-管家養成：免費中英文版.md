## 概述

《從零開始養成我的 AI 管家》是 Farceur Liu 製作的免費公開教材，教使用者如何把 AI 訓練成「能交辦、可驗收、能累積」的工作夥伴。重點不在工具比較，而在方法論。

- 22 章學習路徑 + 4 個實戰案例
- 中文版 + 英文版
- 線上閱讀 + PDF 下載

## 四大核心能力

| 能力 | 說明 |
|------|------|
| 交辦清楚 | 指定目標、資料來源、限制條件、輸出格式 |
| 驗收結果 | 區分事實與假設，維持人類判斷 |
| 累積知識 | 成功方法轉為可重用模板 |
| 選對工具 | 判斷何時用 Chat / Code Interpreter / Workflow / Skill |

## 適用對象

- 第一次在職場使用 AI 的人
- 小團隊導入 AI 工作流
- 想學 Code Interpreter / CLI 工具的人
- 想做流程自動化的人
