## Main Content

Google × Kaggle 推出免費五日課程「AI Agents & Vibe Coding」，教授以自然語言驅動程式開發的 AI Agent 技術。

### 課程資訊

- **日期**：2026 年 6 月 15–19 日
- **費用**：免費
- **平台**：Kaggle
- **形式**：自主進度，每日一主題
- **歷屆規模**：2025 年 11 月場次已有 150 萬+ 學員

### 五日主題

1. AI Agent 基礎與 Vibe Coding（自然語言驅動程式開發）概念
2. Function Calling 與工具整合
3. 多 Agent 通訊系統
4. 生產環境部署架構
5. Capstone Project 實作

### 報名流程（7 步）

1. 建立 Kaggle 帳號
2. 建立 Google 帳號
3. 進入 Google AI Studio 取得 Gemini API 存取權
4. 前往 Kaggle Learn 報名課程
5. 加入 Discord 社群
6. 訂閱 YouTube 頻道觀看每日 Live Q&A
7. 完成 Capstone Project 取得證書（選擇性）

### 使用工具

| 工具 | 用途 |
|------|------|
| Kaggle Notebooks | 雲端程式開發環境 |
| Google AI Studio | Gemini API 存取 |
| Kaggle Learn | 補充 Python 訓練 |
| Discord | 社群互動 |
| YouTube | Live Q&A 直播 |

### 證書與獎勵

完成 Capstone Project 可獲得 Kaggle 官方證書與認可。
