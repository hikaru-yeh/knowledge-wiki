## Main Content

Claude Cowork 真的超方便
想像你在一個汽車品牌上班
每週都需要關注 Benz BMW Audi 的社群動態
現在只要把 prompt 放入 Claude Cowork
再加上爬蟲神器 byCrawl 的 connector
瞬間就獲得爬 IG, Threads, 推特 的能力！
爬完後 AI 馬上整理出對手發文的成效和方向
想知道 byCrawl 可以期待一下
後續會分享更多的爬蟲場景

目前這樣的場景跑一次大概 60 credit 左右
Threads crawler 這種 repo 比較困難應該都是因為需要真的起 browser 去爬，bycrawl apify 等等用的技術應該差不多
要自己搞定瀏覽器這段如果用 AI 去模擬，又非常消耗 AI 的 token

目前這場景是抓週報，所以一個月大概四次
每天都要跑的場景可能就要想一下 credit 的分配
或是該場景的商業價值是否值得惹

有這樣的功能可以使用
或是你也可以丟個關鍵字給我，我跑一次他的最近發文讓你看看結果？

感謝！這算是個簡易 demo 版
業界有需求的話都可以調整成更完整的版本喔

目前已知擋最兇的就是蝦皮，其他都還算好處理
但會用其他第三方工具

要喔也是每月購買積分的制度
跟 Apify 有點像
有比較多的台灣資訊來源網站可以爬

但消耗的 Token 可能不划算喔
通常這種三方 API 就是為了要一次撈蠻大量的資訊下來
用 cowork 讓他去截圖或是操控瀏覽器需要燒的 token
權衡下來不一定划算，還會有穩定性的問題
(最慘就是因為自動化操作被刪社群帳號，Meta 有案例)
