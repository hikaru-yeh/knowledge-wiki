## Main Content

Addy Osmani（谷歌 Gemini 團隊主管）最近開源的 Agent Skills，在 GitHub 上狂攬了 18000+ Star。
它把資深工程師的工作流和開發規範，封裝成 Skills 技能庫，讓 AI 在每個開發階段都能保持一致的高標準。
整個專案圍繞軟體開發生命週期設計，覆蓋「定義、規劃、建構、驗證、評審、發布」六個階段，共計 20 個核心技能。
提供 7 個觸發命令，例如：
/spec 撰寫需求、/plan 拆解任務、/build 撰寫程式碼、/test 執行測試、/ship 部署，每個命令都會自動調用相關技能。
支援 Claude Code、Gemini CLI、Codex、Cursor 等主流 AI 編程工具。
如果你已經在使用 AI 輔助開發，不妨試試這套 Skills，看看能否提升你的交付品質。
