薪資：NTD 45,000 起+獎金（依能力與經驗調整）
工作型態：Hybrid（遠端為主，偶爾至台北辦公室）
我們正在找對 AI workflow、自動化、AI Agent 有高度興趣的人加入 AI郵報。
如果你平常會研究：n8n、Make、小龍蝦、Coze、AI Agent、MCP、RAG、workflow 等，甚至會自己 build workflow、串 API、測新工具，那這個職位會很適合你。

｜你將參與的事情｜
研究與測試最新 AI workflow、自動化工具與 AI Agent 應用
使用 n8n、Make 等工具串接 OpenAI／Claude API 與各類工作平台
建立 AI workflow、Agent demo、自動化流程與知識庫應用
撰寫 AI workflow、自動化、AI Agent 相關教學與研究內容
將研究成果整理為 SOP、案例或課程內容
協助企業探索 AI workflow 與自動化導入可能性

｜我們希望你具備｜
實際使用過如 n8n、Make、Zapier、小龍蝦、Coze 等工具
有 workflow／automation 實作經驗（請附作品或案例）

有實際串接 API、建立 workflow 或自動化流程經驗
對新工具有高度研究熱情，會主動測試與學習
具邏輯思維與問題拆解能力

｜加分條件｜
熟悉 API 串接
具 Python 或 JavaScript 基礎
熟悉 RAG、向量資料庫（Vector Database）概念
曾建立 AI Agent、多步驟 workflow 或知識庫系統
