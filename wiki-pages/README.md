# Wiki Pages

`wiki-pages/` contains the curated knowledge layer maintained by an LLM agent.

The private working vault may contain hundreds of pages. The public scaffold keeps only examples so the architecture is visible without exposing private notes.

Useful examples:

- `wiki-pages/example-topic/example-wiki-page.md`
- `wiki-pages/index/example-index.md`
- `wiki-pages/log.example.md`
