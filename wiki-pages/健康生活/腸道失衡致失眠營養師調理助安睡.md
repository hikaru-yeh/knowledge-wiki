# 腸道失衡致失眠？營養師從體內調理助安睡

若一般助眠方法無效，懷疑腸道處於發炎狀態，導致合成血清素的原料被拿去合成造成神經毒性的物質。

**補充建議（優先序）：**

| 補充品 | 作用 |
|--------|------|
| 魚油 | 抗發炎，神經不發炎才能正常收發睡眠訊號 |
| 維生素 D | 調節發炎 + 從基因層面調節血清素 |
| 益生元 + 益生菌 | 調節腸道環境 |
| GABA + 鎂 + 維生素 B6 | 直接助眠 |
| 南非醉茄（Ashwagandha）| 降低皮質醇：白天飯後吃穩定情緒；若睡前亢奮可睡前或晚餐後服用 |

**備注：**
- 色胺酸：多數食物都有，不太需要額外補充
- 若懷疑食物過敏，需先找出過敏源，搭配麩醯胺酸（Glutamine）和益生菌修復腸道
