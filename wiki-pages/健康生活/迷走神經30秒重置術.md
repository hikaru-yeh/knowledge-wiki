迷走神經（Vagus Nerve）是人體最長的顱神經，從腦幹延伸到腹部，調節心率、消化、呼吸與情緒反應。「迷走神經張力」（Vagal Tone）越高，從壓力中恢復的能力越強。

**10 個動作（每個 30 秒），按科學依據強弱排列：**

| 方法 | 機制 | 科學依據 |
|------|------|---------|
| 腹式深呼吸 | 呼氣比吸氣長（4 秒吸 / 6 秒吐），橫膈膜運動牽動迷走神經 | ★★★ 最強 |
| 耳朵按摩（耳珠）| 迷走神經耳支分布於外耳，taVNS 醫療原理 | ★★★ 最強 |
| 冷水潑臉 | 觸發潛水反射，三叉神經→迷走神經→心率下降 | ★★★ 最強 |
| 哼唱或低吟 | 聲帶振動刺激迷走神經，提升 HRV | ★★ 中等 |
| 全身抖動 | TRE 神經性震顫，釋放肌肉張力（初步研究）| ★ 初步 |
| 輕拍下巴、頸部 | 改善血液循環，放鬆頸肌（非直接迷走刺激）| ★ 輔助 |
| 漱口 | 軟顎與咽喉肌肉收縮（解剖學推論，缺乏直接研究）| ★ 輔助 |
| 眼球側視 | Polyvagal Theory（初步研究）| ★ 輔助 |
| 手掌遮眼 | 遮光讓感官休息（瑜伽傳統）| ★ 輔助 |
| 嗅聞精油 | 薰衣草透過嗅覺間接影響情緒（非直接迷走刺激）| ★ 輔助 |

**建議起點：** 腹式深呼吸 + 冷水潑臉 + 耳朵按摩（研究最紮實的三個）
