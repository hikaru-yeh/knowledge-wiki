# 問答模板

對 wiki 提問的標準模板。問答結果請存入 `wiki/衍生/問答/`。

---

## 基礎問答

```
讀取 wiki/索引/總索引.md，
然後根據需要讀取相關的概念文章，
回答：[你的問題]

回答格式：繁體中文，重點條列，300字以內。
```

## 跨主題研究

```
我想深入了解 [主題A] 和 [主題B] 的關聯。
請先讀 wiki/概念/[主題A].md 和 wiki/概念/[主題B].md，
找出：1) 共同模式 2) 互補之處 3) 可能的整合方式

結果請存入 wiki/衍生/問答/[主題A]-vs-[主題B].md
```

## 找新文章候選

```
讀取 wiki/索引/總索引.md 和所有概念文章，
找出：
1. 被多個文章提到但沒有獨立概念文章的主題
2. 目前概念文章之間缺少的橋接概念
3. 建議新增的3個概念文章標題

格式：
- 概念名稱：[name]
- 被哪些文章提到：[list]
- 建議原因：[reason]
```

## 學習路徑生成

```
我想學習 [技能/主題]，
請讀取 wiki/ 中所有相關文章，
為我設計一個學習路徑：

1. 先讀什麼（基礎）
2. 再讀什麼（中級）
3. 最後讀什麼（進階）
4. 還缺少哪些資料（需要補充到 raw/）
```

## 行動計劃生成

```
根據 wiki/概念/[主題].md 的知識，
為我生成一個具體的30天行動計劃，
每週3個可執行任務，每個任務限一行。
存入 wiki/衍生/問答/[主題]-行動計劃.md
```
