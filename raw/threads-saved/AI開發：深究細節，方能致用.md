## 主文

說實在的，我開發系統也有10幾年了，這跟是不是資工沒有絕對關係，善用AI是件好事，只是初生之犢不畏虎，很多素人剛接觸到Claude Code 會真的以為拿到神兵利器，但玩久了，如果沒有資深人士帶入門，只靠皮毛就想做網站平台，真的不是你們想像中那麼簡單，細節真的太多了，隨便一個資安漏洞都能把人搞死，前後台之間要做登入，是走API還是OAuth? 有什麼差別？
要純前端還是SSR? 個資要怎麼保護？ 封包加密如何處理？ 這些還都只是剛入門的知識而已，但AI不會主動幫你做，因為你也不知道怎麼問

## 作者留言

厲害的資工系很多都進大公司或銀行系統，證券系統那些，基本上有摸到敏感資訊的工作很難被取代，如果是業界一般的系統維護或開發，中階（含）以下的工程師差不多是搖搖欲墜，很多團隊原本分工超細，後端工程師寫寫API，做做Test，修Bug的日常，然後就沒了，這種維護工程師比較危險，但原本執掌RD的人員用了AI反而更像是一人當五人用。只要原本就掌握企業的領域知識，是很難被洗掉的，最有價值的員工其實是腦子裏裝有大局思考的人

你說的很有道理，是內行的，沒AI以前我們會刻components來讓邏輯層調用，如果沒這習慣的人用Vibe做出來的就是一大堆「義大利麵」那種inline code

是有很多，但不是"都"，銀行的資訊系統很講究正規化，一絲不苟的SOP，不能說改就改的，所以很多老舊系統只能靠那些資工系培養出來的龜毛工程師才能擔當

我們都到要去哪找工具，因為熟悉，也懶得造輪子，只是沒有這些sense的人要到這一步全憑運氣

我每隔一週都要追AI領域的新進度，所有工具我都會直接用看看，但不是所有都適用，一但產品上線後就不能隨意亂更動
