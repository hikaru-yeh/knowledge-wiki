## 主文

新手使用 Agent 推薦：
使用 Claude Cowork，文書工作流程超友善，可以只選一個資料夾，AI 只能動那個資料夾裡的東西。每一步要做什麼都會先問你。
我會先建議複製一份檔案出來，讓 AI 做測試跟練習，不要直接動你正式的工作檔案。確認內容都正確，再複製回去就好。
等你熟悉之後，你會覺得每次都要按確認有點煩。如果你希望它可以全自動幫你做事，那就可以試試 Claude Code。
不過在那之前，你要先確定幾件事：
- 整個工作流程你已經跑得很順了
- 已經有寫 Skill，就是預先寫好的操作手冊，讓AI能照著做。
- 你的目的和需求都很清楚，AI 可以動的權限範圍也都交代好了
- 要有備份
在這樣的前提下，Claude Code 的全自動模式就會非常爽。
最常用的情境是下午要出門開會、晚上要睡覺前，我就先用 Plan mode 讓它把整個規劃寫好給我看。確認沒問題之後，切到 Bypass 模式，跟它說：「全部跑完吧，遇到問題自己判斷，跑完寫工作日誌給我看。」

目前 Claude Code 有四種權限模式：
🔸 Ask permissions（每次都問）
跟 Cowork 一樣，每個動作都先問你。從這裡開始最安全。
🔸 Auto accept edits（自動接受編輯）
檔案的新增跟修改會自動通過，但如果 AI 要執行系統指令，像是安裝套件、刪除檔案、跑程式這類有風險的操作，還是會先問你。
🔸 Plan mode（先規劃再動手）
AI 不會直接動檔案，而是先寫一份完整的執行計畫給你看。你確認沒問題，再切回去讓它一口氣跑完。
🔸 Bypass permissions（全自動）
所有操作直接執行，不問你。如果 AI 判斷錯誤，它不會停下來問你，直接做完你才會發現。
