➊ 一定要用 Terminal 嗎？
不一定。Claude Code 也可以在 Desktop App、IDE、Browser 裡使用，比起選載體，更重要的是先想清楚你想用它解決什麼問題。
➋ Terminal 要怎麼選？
我公司用 Ghostty，私人電腦用 Warp。如果你剛開始接觸，我建議先從 Warp 入手，指令輸出整齊、支援自然語言、還有 File Tree 可以直觀瀏覽專案結構。對設計師來說最重要的是——介面很好看 XD
➌ 怎麼用講的代替打字？
Wispr Flow 支援 100+ 種語言，我平常工作會混著中、英、日三種語言加上設計術語，它的辨識仍然相當準確。最大的價值是降低把腦中想法整理成文字的阻力

➍ 什麼是 Context Window？
AI 在單個 Session 裡的工作記憶，包含對話、讀過的檔案、跑過的輸出。用超過 70%（體感數字）之後回覆品質容易開始下降，也就是大家說的「鬼擋牆」
➎ 怎麼有效管理 Context Window？
/compact 主動壓縮（不要等壞掉才用）、Plan Mode 把探索跟實作拆開避免白燒 Token、以及請 Claude 整理交接文件後開新 Session 繼續推進
➏ 不知道 Claude Code 能做什麼，要先研究才能開始嗎？
不用！先問就對了，它才會慢慢長成你的第二大腦～
