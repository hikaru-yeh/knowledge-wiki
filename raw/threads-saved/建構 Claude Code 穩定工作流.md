## 主文

如果你也開始研究 Claude Code skill
我會建議先不要做成一包很帥的技能庫
先做一條每天真的會用到的交付線就好
例如把「需求 -> 拆任務 -> 改程式 -> 自測 -> 回報」固定成一套 skill
讓它每次都照同一個順序跑
這樣你才看得出來
它到底是在幫你省時間
還是在幫你更快產生一堆要重修的東西
