## 主文

LLM wiki 很紅但我覺得我本來用法很像就差不多說⋯⋯主要是因為我的 Claude 為了避免記憶污染從一年多前註冊開始就沒開過帳號記憶功能，每一個對話都是新的。而我使用 Claude Code 方式就是工作目錄直接設定成 Obsidian 的 Vault，一開始也只是因為這樣方便修改 CLAUDE.md 跟他寫的文件，以及我要寫文件跟資料給他閱讀都在 Obsidian 搞定就好，每次 Session 我也都會叫他整理交接資料（直接寫在帳號設定） 輸出後下一輪對話可以直接讀，有交叉參考資料也是直接讓他做 index，我其實一直都這樣用因為記憶污染真的痛苦！他自己記憶的話會記住不需要的資訊，所以一直以來為了節省 context 我都不開全域記憶，我覺得這是我用起來最順手的方式！不要讓他亂塞記憶亂燒 Token！
