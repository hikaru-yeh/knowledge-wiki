接續上一篇，這就是讓 Claude 複刻 Justin Welsh $800 萬美金商業框架 的實戰咒語（Prompt）。
這套系統我建議照順序跑，把括號裡的內容換成你自己的實況。如果你覺得現在的事業做得很累、產出不穩定，跑完這幾個指令，你會有種豁然開朗的感覺。
這才是真正的「AI 懶人獲利術」：讓 AI 幫你設計系統，而你負責執行。
咒語在留言區，記得先收藏

Prompt 1：定義你的商業模式
「你是一位專精 Justin Welsh 框架的一人公司策略師。我的利基是 [你的領域]，目前技能是 [你的專長]，目標是每月獲利 [金額]。請幫我建立一套完整的一人商業模型，包含核心產品、內容切入點與營收來源。規則：必須由我獨自執行，不需團隊，不需廣告預算。」

Prompt 2：打造內容增長策略
「你是一位內容增長專家。我正在 [你的領域] 建立事業，目標是吸引 [目標受眾] 購買 [你的產品]。請提供我 30 天的內容策略，包含主題、格式與每週重複的發布排程。目標：建立信任感並將我定位為該領域的專家。」

Prompt 3：設計你的招牌產品（Offer）
「我擅長 [專業知識]，我的受眾面臨 [具體問題]。請幫我設計一個『標準化服務』或『數位產品』，包含名稱、帶來的結果、定價與交付方式。規則：一人即可完成，不需客製化，且能解決一個特定的核心痛點。」

Prompt 4：寫出你的個人品牌故事
「我的背景是 [你的背景]，我如何從 [舊狀態] 轉換到 [現在的事業]。請以第一人稱幫我寫一段品牌故事。語氣要真誠、像個真人，讓我的理想客戶感覺到我完全理解他們現在的處境。」
