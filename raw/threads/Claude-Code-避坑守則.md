歡迎使用 Claude Code，
為了確保您的荷包安全與身心健康，建議遵守以下規則：
1. 如果 context 已經很長，而且你已經離開超過 1 小時，請不要繼續。
2. 如果它開始一直問你剛剛已經講過的事，請停下來，要求它先整理「目前它以為的任務、已知事實」
3. 如果它突然用其他語言回覆你，但你沒有要求它切換語言，不要理會，請它記錄進度，然後默默關掉這個 Session。
4. 如果它說『完成了』但沒有附上驗證或說明，請不要相信，它很可能在騙你。
5. 如果它找一個東西找了很久都還沒找到，並且你注意到額度持續在消耗，請先輕聲詢問它「在找什麼、目前找到什麼」
6. 如果它要修改或刪除檔案，但沒有先規劃，請停下來，要求它先規畫一個修改計畫。
8. 計畫是可以信任的，多數時候。
9. 避免使用昂貴模型進行網路搜索或大量讀取的任務。
10. 如果同一個錯誤修了 3 次還沒好，不要讓它繼續試。
11. 這份文件有 11 條規則。如果你數出來不是 11 條，從第一條重新讀。
