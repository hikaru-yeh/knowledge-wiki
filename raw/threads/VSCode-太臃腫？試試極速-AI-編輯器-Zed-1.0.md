推薦所有覺得 VSCode 很臃腫想換換 Editor 的人都來用用看 Zed，昨天發布 1.0 版了

只是要編輯一個小檔案懶得開 VSCode，內建的記事本又沒有語法提示？
Zed 是一個用 Rust 開發的 Editor，開檔案、切換專案幾乎都是秒開

Zed 支援使用官方的 Zed AI 或 Github Copilot 做 AI Completion
也能嵌入包含 Gemini CLI、Codex、Claude Code 等多家 CLI，聊天室跟使用介面統一
